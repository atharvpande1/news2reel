Now we need to start building the next stages of the workflow: the user selects upto 8 stories (so a max of 10 slides, with one intro and one cta) to generate the hightlights carousel slides. After clicking next the user moves from the data gathering phase into the Creative Canvas. This should feel like a lightning-fast assembly line.

After selecting and clicking next, the user should be able to see the instagram compatible carousel slides in the canvas. Each slide should have a headline/hook (AI generated from the raw headline and summary) in the bottom of the slide, and for now let's keep the background white, without any image or anything. The story slides would be sandwiched between the intro and cta slides.
For the generated story headline/hook, follow these rules:
1. COMPLETENESS: The hook must feel like a complete, standalone news sentence. It must answer "What happened?" and "Where?". Do not write open-ended clickbait (e.g., Avoid: "You won't believe what happened in Kothrud").
2. LENGTH LIMIT: The hook MUST be between 60 and 85 characters long (including spaces). This is a strict design layout boundary.
3. TONE: Informative, objective, and urgent. Use active voice verbs.
4. LANGUAGE: English only for this phase.

Every slide should be editable (text only). The story slides should  be ranked by the engagement score, but the user can reorder them via drag and drop. The user can also delete a slide or bring it back.

Once the user is done editing, they can download the carousel as a set of jpeg/jpg images in a zip file.
